# TT Training

Tischtennis-Übungen für zwei Spieler – 100 geprüfte Übungen, Würfel, Einheiten, Plan und Statistik.

**App öffnen:** https://felixk294.github.io/tt-training/

Auf dem iPhone in Safari öffnen, dann **Teilen → „Zum Home-Bildschirm“**. Danach läuft die App komplett offline auf dem Gerät; alle Daten bleiben auf dem Handy.
